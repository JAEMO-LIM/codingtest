# 코딩테스트 풀이 저장소

## 패키지 구조

```
src/main/java/net/zero123/
├── programmers/          # 프로그래머스
│   ├── level1/
│   ├── level2/
│   ├── level3/
│   ├── level4/
│   └── level5/
└── codetree/             # 코드트리
    ├── novice/           # 입문
    ├── intermediate/     # 초·중급
    ├── advanced/         # 고급
    └── master/           # 마스터
```

## 파일 네이밍 컨벤션

| 플랫폼 | 형식 | 예시 |
|--------|------|------|
| 프로그래머스 | `P{문제번호}_{문제이름}.java` | `P12345_두개뽑아서더하기.java` |
| 코드트리 | `CT_{문제이름}.java` | `CT_최소공배수.java` |
